# UFC 선수 비교 분석기

Play Lab Academy 2기 개인프로젝트 · 과제 1 (타 스포츠 데이터분석 웹사이트 제작)

## 1. 왜 만들었나 (문제 정의)
UFC 팬들 사이에서 "저 선수 진짜 세냐", "이번에 붙으면 누가 이길까" 같은 논쟁은
늘 하이라이트 영상 몇 개, 기억에 남는 장면 하나로 결론이 나버립니다.
하지만 UFC는 경기마다 유효타 수, 테이크다운 성공률, 컨트롤 타임까지 상세히
기록되는 스포츠입니다. 이 사이트는 그 기록을 근거로 **감이 아니라 데이터로**
두 선수를 비교하고, 체급 전체의 흐름까지 읽을 수 있게 만든 것이 목적입니다.

- 타깃 사용자: UFC를 꾸준히 챙겨보는 팬 / 격투기 커뮤니티 이용자
- 해결하려는 질문: 두 선수의 전적·스타일·상세 스탯을 비교하면 어떤 강점 차이가 보이는가?
  체급은 시대에 따라 어떻게 달라졌는가?

## 2. 사람들이 이걸로 할 수 있는 것
1. 두 선수를 골라 전적·승리 방식·타격/그래플링 스탯을 나란히 비교해서
   "맞대결 논쟁"에 실제 근거 자료로 활용
2. 좋아하는 선수의 커리어 전체 패턴(어떻게 이기고 지는 선수인가)을 확인
3. 관심 체급이 최근 몇 년 사이 어떻게 바뀌었는지(피니시율 변화 등) 트렌드로 파악

## 3. 데이터
- 출처: [scrape_ufc_stats](https://github.com/Greco1899/scrape_ufc_stats) (GitHub, 공개 저장소)
  - 원자료: ufcstats.com 공식 기록을 매일 자동으로 스크래핑해 갱신
- 기간: **1994년 ~ 2026년 8월 (가장 최근 이벤트까지 반영된 최신 데이터)**, 경기 약 8,860건, 선수 약 2,740명
- 원본 파일(raw/) → 가공 스크립트(`data_prep.py`) → 앱이 사용하는 파일(data/)
  - `data/ufc_fights.csv`: 경기별 결과 (승자/패자/방식/날짜/이벤트/체급/정규화된 체급명)
  - `data/ufc_fighter_bio.csv`: 선수 신체 정보 (신장/리치/스탠스/생년월일)
  - `data/ufc_fighter_career_stats.csv`: 선수별 커리어 합산 스탯 (경기당 유효타,
    유효타 정확도, 테이크다운 성공률, 컨트롤 타임 등 — 라운드별 원자료를 집계)
- 전처리: 이벤트-경기 결과 조인으로 날짜 부여, 승패 결과(OUTCOME) 파싱, 승리 방식(KO/TKO·
  Submission·Decision) 표준화, 체급 표기 120종 → 15개 핵심 체급으로 정규화, "X of Y" 형태의
  타격/테이크다운 기록을 숫자로 분리해 선수별 커리어 스탯 집계
- **한계**: 코치·초기 UFC(1994년 초반) 경기는 상세 스탯이 없는 경우가 있어 일부 선수는
  "상세 경기 통계 데이터 없음"으로 표시됨. 체급 이동(복수 체급 활동) 선수는 전체 체급
  합산 전적으로만 표시됨.

## 4. 분석 / 기능
- 전체 경기 승리 방식(KO·TKO/Submission/Decision) 분포
- 두 선수 비교: 전적, 승률, 승리 방식별 비교, 유효타/테이크다운 정확도, 맞대결 기록, 신체 스펙
- 체급별 트렌드: 체급 선택 시 승리 방식 분포 + 연도별 피니시(KO·서브미션) 비율 변화 추이

## 5. 실행 방법 (로컬)
```bash
pip install -r requirements.txt
streamlit run app.py
```
데이터를 다시 최신화하려면 `raw/`에 scrape_ufc_stats의 5개 원본 csv를 넣고
`python data_prep.py`를 실행하면 `data/` 폴더가 갱신됩니다.

## 6. 배포 방법 (Streamlit Community Cloud, 무료)
1. GitHub에 새 저장소를 만들고 이 폴더(app.py, requirements.txt, data/ 전체)를 업로드합니다.
2. [share.streamlit.io](https://share.streamlit.io) 에 GitHub 계정으로 로그인합니다.
3. "New app" → 방금 올린 저장소 선택 → Main file path에 `app.py` 입력 → Deploy 클릭.
4. 몇 분 뒤 `https://[앱이름].streamlit.app` 형태의 공개 URL이 생성됩니다.
5. 이 URL을 과제보고서·발표자료의 "접속 링크"에 기재하면 됩니다.

## 7. 향후 개선 방향
- 스탠딩/그라운드 게임 스타일 군집화(비지도학습)로 "유사 스타일 선수 찾기" 기능 추가
- 체급 이동 선수의 체급별 전적 분리 표시
- 최근 5경기 폼(컨디션) 지표 추가
