# UFC 선수 비교 분석기

Play Lab Academy 2기 개인프로젝트 · 과제 1 (타 스포츠 데이터분석 웹사이트 제작)

## 1. 왜 만들었나 (문제 정의)
UFC 팬들 사이에서 "저 선수 진짜 세냐", "이번에 붙으면 누가 이길까" 같은 논쟁은
늘 하이라이트 영상 몇 개, 기억에 남는 장면 하나로 결론이 나버립니다.
하지만 UFC는 경기마다 유효타 수, 테이크다운 성공률, 컨트롤 타임까지 상세히
기록되는 스포츠입니다. 이 사이트는 그 기록을 근거로 **감이 아니라 데이터로**
두 선수를 비교하고, 체급 전체의 흐름까지 읽을 수 있게 만든 것이 목적입니다.
a
- 타깃 사용자: UFC를 꾸준히 챙겨보는 팬 / 격투기 커뮤니티 이용자
- 해결하려는 질문: 두 선수의 전적·스타일·상세 스탯을 비교하면 어떤 강점 차이가 보이는가?
  체급은 시대에 따라 어떻게 달라졌는가?a

## 2. 사람들이 이걸로 할 수 있는 것
1. 두 선수를 골라 전적·승리 방식·타격/그래플링 스탯을 나란히 비교하고,
   **레이더 차트**로 두 선수의 스타일(그래플러형 vs 타격가형) 차이를 한눈에 확인
2. 좋아하는 선수의 커리어 전체 패턴(어떻게 이기고 지는 선수인가)을 확인하고,
   바로 유튜브에서 해당 매치업 하이라이트를 찾아볼 수 있음
3. 관심 체급이 최근 몇 년 사이 어떻게 바뀌었는지 — 피니시율, 타격 vs 그래플링
   승리 비중 변화 등 — 트렌드로 파악
4. 김동현·정찬성·최두호 등 한국 팬들에게 익숙한 선수들의 스타일을 데이터로 비교

## 3. 데이터
- 출처: [scrape_ufc_stats](https://github.com/Greco1899/scrape_ufc_stats) (GitHub, 공개 저장소)
  - 원자료: ufcstats.com 공식 기록을 매일 자동으로 스크래핑해 갱신
- 기간: **1994년 ~ 2026년 8월 (가장 최근 이벤트까지 반영된 최신 데이터)**, 경기 약 8,860건, 선수 약 2,740명
- 원본 파일(raw/) → 가공 스크립트(`data_prep.py`) → 앱이 사용하는 파일(data/)
  - `data/ufc_fights.csv`: 경기별 결과 (승자/패자/방식/날짜/이벤트/체급/정규화된 체급명)
  - `data/ufc_fighter_bio.csv`: 선수 신체 정보 (신장/리치/스탠스/생년월일)
  - `data/ufc_fighter_career_stats.csv`: 선수별 커리어 합산 스탯 (경기당 유효타,
    유효타 정확도, 테이크다운 성공률, 컨트롤 타임 등 — 라운드별 원자료를 집계)
- 전처리: 이벤트-경기 결과 조인으로 날짜 부여, 승패 결과(OUTCOME) 파싱, 승리 방식(KO/TKO·
  Submission·Decision) 표준화, 체급 표기 120종 → 15개 핵심 체급으로 정규화, "X of Y" 형태의
  타격/테이크다운 기록을 숫자로 분리해 선수별 커리어 스탯 집계
- **한계**: 코치·초기 UFC(1994년 초반) 경기는 상세 스탯이 없는 경우가 있어 일부 선수는
  "상세 경기 통계 데이터 없음"으로 표시됨. 체급 이동(복수 체급 활동) 선수는 전체 체급
  합산 전적으로만 표시됨.

## 4. 분석 / 기능
- **소개 페이지**: 사이트 전체를 한눈에 훑을 수 있도록 핵심 지표(전체 경기 수·선수 수·데이터
  기간), 세 가지 기능을 소개하는 미리보기 카드(각 카드의 "바로가기" 버튼을 누르면 바로 그
  화면으로 이동), 스타일이 정반대인 두 선수(마카체프 vs 맥그리거)를 겹친 레이더 차트 미리보기로
  구성 — 처음 들어온 사람이 스크롤 없이도 "이 사이트가 뭘 보여주는지" 바로 알 수 있게 설계
- 전체 경기 승리 방식(KO·TKO/Submission/Decision) 분포
- **선수 비교**: 전적, 승률, 승리 방식별 비교, 유효타/테이크다운 정확도, 맞대결 기록, 신체 스펙,
  **레이더 차트로 본 스타일 비교**(경기당 유효타·정확도·테이크다운·컨트롤타임·서브미션 시도·
  승률 6개 지표를 전체 선수 대비 백분위로 환산해 겹쳐 그림), 매치업 하이라이트 유튜브 검색 링크.
  전적·스탯 / 스타일 레이더 / 맞대결·하이라이트 3개 탭으로 나눠서 한 화면에 정보가 몰리지
  않도록 구성. 레이더 차트 밑에는 6개 지표가 각각 무슨 뜻인지 펼쳐볼 수 있는 설명을 추가해
  UFC를 잘 모르는 사람도 바로 이해할 수 있게 함
- **선수 얼굴 사진**: `data/photos/<이름>.jpg` 로컬 파일이 있으면 최우선으로 사용하고,
  없으면 영어 위키백과 → 한국어 위키백과 → Wikidata 순서로 실시간 조회, 그래도 없으면
  이니셜 아바타로 자동 대체 (2,740명 전원을 직접 수급하는 대신, 선택된 선수만 그때그때
  조회 + 필요한 선수만 직접 사진 추가 가능한 구조). 최두호처럼 위키백과 계열에 사진이
  전혀 없는 선수는 `data/photos/`에 직접 파일을 넣어 해결할 수 있음 (사용법은 그 폴더의
  README.md 참고)
- **스타일 자동 분류 (그래플러형 / 타격가형 / 올라운더형)**: "감"이 아니라 데이터로
  분류 — 테이크다운 정확도·컨트롤타임·서브미션 시도(그래플링 지표)와 유효타 정확도·빈도
  (타격 지표)를 각각 전체 선수 대비 백분위로 평균 내 비교. 실제로 Islam Makhachev(그래플러형),
  Conor McGregor(타격가형), 김동현(그래플러형), 최두호(타격가형)로 정확히 분류됨을 확인.
  이모지 대신 색상 배지(pill)로 표시
- **체급별 트렌드**: 체급 선택 시 그 체급 **대표 선수 카드**(최다승 TOP 3의 얼굴·스타일 배지를
  바로 보여줘서 숫자만이 아니라 "누가 이 체급을 대표하는 선수인지" 감을 잡을 수 있게 함),
  승리 방식 분포, 연도별 피니시(KO·서브미션) 비율 변화, **연도별 승리 방식(타격 vs 그래플링)
  비중 변화 라인차트**, 체급 내 최다승 TOP 5 리더보드
- **한국 파이터 스포트라이트**(신규 페이지): 김동현·정찬성·최두호의 실제 사진과 스타일
  배지를 카드로 보여주고, 같은 레이더 차트 위에 겹쳐서 스타일 차이를 데이터로 시각화
- **다크 테마 + 스포츠 중계 느낌의 타이포그래피**: UFC.com 등 실제 격투기/스포츠 사이트를
  참고해 어두운 배경 + 레드 포인트 컬러로 전환, 스탯 라벨은 대문자·자간을 넓혀 중계 화면
  느낌으로, 큰 숫자는 굵게. 승리 방식(Decision/KO·TKO/Submission/DQ)은 어느 화면에서나
  항상 같은 색(다크 서피스에 맞게 재보정된 색상)으로 표시되도록 고정 매핑 유지. 카드형
  레이아웃 + 둥근 모서리 + 그림자로 정보 단위를 구분하고, 장식용 이모지는 페이지 아이콘
  1개씩으로 최소화(과도한 이모지 사용은 지양)

### 피어 멘토 피드백 반영 내역
- "레이더 차트로 스타일 보여주면 좋겠다" → 선수 비교/한국 파이터 페이지에 레이더 차트 추가
- "체급별 트렌드가 승리 방식으로만 시각화됨, 다각화 필요" → 연도별 타격 vs 그래플링
  비중 변화 라인차트 추가
- "한국 팬 대상이니 김동현/정찬성/최두호 같은 선수 보여주면 좋겠다" → 한국 파이터
  스포트라이트 페이지 신설
- "선수 얼굴이 있으면 더 좋겠다", "한국 선수는 얼굴이 꼭 나왔으면" → Wikipedia 공개 API로
  선수 사진을 실시간 조회해 표시 (사진이 없는 선수는 이니셜 아바타로 자동 대체)
- "타격가/그래플러를 데이터로 명확히 구분해달라" → 그래플링 지표 vs 타격 지표의 백분위
  평균 차이로 스타일을 자동 분류하는 배지 추가 (레이더 차트 옆에 함께 표시)
- "다른 UFC 사이트, 특히 UFC 공식 홈페이지를 벤치마킹해서 디자인을 더 다듬어달라" →
  어두운 배경 + 레드 포인트 컬러의 스포츠 중계 스타일로 전환, 큰 숫자·대문자 라벨로
  스탯이 눈에 띄게, 장식용 이모지를 페이지 아이콘 1개로 최소화
- "유튜브 하이라이트 영상 등 멀티소스 데이터 조인" → API 연동 없이도 바로 쓸 수 있는
  경량 버전으로, 매치업 선택 시 유튜브 검색 링크를 자동 생성해 연결. 실제 영상
  썸네일·통계까지 조인하는 것은 시간상 향후 과제로 남김
- "Kaggle의 다른 UFC 데이터셋과 조인해서 다각화" → 이번에는 시간 관계상 반영하지
  못했고, 향후 개선 방향에 명시함 (기존 데이터 파이프라인이 안정적으로 동작 중인
  상태에서 마감 직전에 새 데이터 소스를 조인하는 것은 리스크가 크다고 판단)

## 5. 실행 방법 (로컬)
```bash
pip install -r requirements.txt
streamlit run app.py
```
데이터를 다시 최신화하려면 `raw/`에 scrape_ufc_stats의 5개 원본 csv를 넣고
`python data_prep.py`를 실행하면 `data/` 폴더가 갱신됩니다.

## 6. 배포 방법 (Streamlit Community Cloud, 무료)
1. GitHub에 새 저장소를 만들고 이 폴더(app.py, requirements.txt, data/ 전체)를 업로드합니다.
2. [share.streamlit.io](https://share.streamlit.io) 에 GitHub 계정으로 로그인합니다.
3. "New app" → 방금 올린 저장소 선택 → Main file path에 `app.py` 입력 → Deploy 클릭.
4. 몇 분 뒤 `https://[앱이름].streamlit.app` 형태의 공개 URL이 생성됩니다.
5. 이 URL을 과제보고서·발표자료의 "접속 링크"에 기재하면 됩니다.

## 7. 향후 개선 방향
- 선수 사진을 Wikipedia 실시간 조회가 아니라 자체 캐시/DB로 저장해 응답 속도와 안정성 개선
- 유튜브 Data API 연동으로 검색 링크가 아닌 실제 하이라이트 영상 임베드 + 조회수 등
  영상 플랫폼 데이터를 UFC 기록과 실제로 조인
- Kaggle의 별도 UFC 데이터셋(1996-2024)과 조인해 배당률(odds) 등 추가 지표 다각화
- 코너 맥그리거처럼 특정 선수의 커리어 "티어(전성기~하락)" 변화를 시계열로 보여주는
  선수별 폼 추이 페이지
- 스탠딩/그라운드 게임 스타일 군집화(비지도학습)로 "유사 스타일 선수 찾기" 기능 추가
- 체급 이동 선수의 체급별 전적 분리 표시
- 최근 5경기 폼(컨디션) 지표 추가
